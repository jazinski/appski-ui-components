Add Gauge: a radial dial for single-value metrics with threshold bands. The value arc takes the tone of the green/amber/red band it lands in (tones fully configurable per band), rendered as inline SVG with theme tokens via currentColor — light and dark mode automatic. Supports min/max scales, unit/decimals formatting for the center value, sublabel, centerLabel override, size variants, and WAI-ARIA img semantics with a generated label. Companion to MetricCard for at-a-glance limit metrics (CPU %, disk, memory, NAS capacity, bowling-average dials).
